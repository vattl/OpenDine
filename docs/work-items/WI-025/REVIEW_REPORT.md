## Axes Reviewed

- 正确性：支付、退款、冲正的金额正负号、原流水关联、精确幂等及订单投影顺序。
- 并发/事务：订单行锁、钱包和订单更新回滚、微信回调与收银竞争、提交后履约。
- 架构：`PaymentLedgerService` 保持资金生命周期唯一所有者；后台结账委托统一收银服务；读取路径保持只读。
- 多门店/安全：订单由门店上下文锁定或从锁定订单推导门店；未新增密钥读取或日志泄露面。
- 性能：日结一致性审计按门店及每 500 个订单批量读取流水，避免逐单 N+1。
- 兼容性：API 路径与成功结构不变，仅增加严格错误和日结阻断语义。
