## Axes Reviewed

- 金额正确性：支付成功必须精确等于当前订单净应付，不再把差额伪装成折扣或退款。
- 并发与原子性：预支付、回调和所有已识别金额变更入口共享订单行锁；退菜在库存、明细和 KDS 动作前先处理旧支付，外部关单失败会回滚本地写入。
- 权威资金事实：成功回调与收银手工结账均在同一事务内先写/校验 `t_payment_ledger`，再更新订单；订单更新失败也会回滚流水。
- 幂等与重复收款：同一尝试可安全复用；金额/付款人/商户路由变化必须收敛旧单后生成新商户单号；第二个成功交易拒绝覆盖。
- 外部状态：只在权威 NOTPAY 后关单；SUCCESS 转公共入账；超时和未知状态保留活动键并阻止重试创建。
- 多门店与商户证书：尝试绑定 shop、merchant config id/version、appid、mchid 和 payer，回调精确匹配。
- 兼容性：原有成功字段保留，新元数据为加法；充值、Native、付款码、现金、余额和挂账通过全量回归。
- 可维护性：尝试状态持久化、金额变更守卫集中、整数分金额、错误路径显式且可追踪。
