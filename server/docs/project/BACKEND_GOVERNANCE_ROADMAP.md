## 兼容与强制策略

1. Observe：新增指标，识别旧字段、旧权限和兼容路由的真实调用量。
2. Warn：响应警告头/审计事件提示迁移，但不静默改变业务结果。
3. Enforce：仅在客户端最低版本、迁移数据和回滚开关明确后强制新约束。
4. Remove：满足零调用观察期且 Contract Handoff 已关闭后删除旧入口。

每个兼容开关只能回退“新约束的强制校验”，不得回退支付或 KDS 的业务权威，不得恢复审批令牌明文存储。
