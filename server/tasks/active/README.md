# Active Tasks

Currently in-progress task breakdowns are stored here.

## Naming Convention

`FXXX.md` for feature tasks
`BUGXXX.md` for bug fix tasks

Example: `F001.md`

## Task Format

Each task file contains a list of independently verifiable tasks:

```
T001 — Task description

Definition of Done:
- Criterion 1
- Criterion 2
- Criterion 3
```

## Workflow

1. Tasks are created during feature/bug planning
2. Active tasks live here
3. Completed tasks are moved to ../completed/
